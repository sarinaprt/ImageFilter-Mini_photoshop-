# ImageFilter-Mini_photoshop-
A Python-based image editor built with Tkinter and OpenCV, featuring image filters, real-time previews, image comparison, and saving edited images.



مینی فتوشاپ(Mini Photoshop )

یک برنامه ساده برای ویرایش تصاویر است که با استفاده از پایتون، Tkinter و OpenCV توسعه داده شده است.

قابلیت‌ها

بارگذاری تصاویر از کامپیوتر
اعمال فیلترهای تصویری مانند Gaussian Blur، Median Blur، Box Blur و Bilateral Filter
افزایش وضوح و شارپ کردن تصاویر (Sharpen)
چرخاندن و برگرداندن تصاویر (Rotate & Flip)
افزودن نویز گاوسی (Gaussian Noise)
مشاهده پیش‌نمایش فیلترها پیش از اعمال نهایی
مقایسه تصویر اصلی با تصویر ویرایش‌شده
ذخیره تصویر ویرایش‌شده در کامپیوتر
فناوری‌های استفاده‌شده

Python: زبان برنامه‌نویسی اصلی پروژه
Tkinter: طراحی رابط کاربری گرافیکی
OpenCV: پردازش و ویرایش تصاویر
NumPy: انجام محاسبات و عملیات آرایه‌ای روی تصاویر
Pillow: تبدیل و نمایش تصاویر در رابط کاربری

هدف پروژه

این پروژه با هدف یادگیری و تمرین برنامه‌نویسی رابط کاربری گرافیکی در پایتون و آشنایی با مفاهیم پردازش تصویر توسعه داده شده است.
در این برنامه، از Tkinter برای ساخت یک ویرایشگر تصویر تعاملی و از OpenCV برای اعمال عملیات پردازش تصویر استفاده شده است.


## Feature

- Upload images from your computer
- Apply image filters, including Gaussian Blur, Median Blur, Box Blur, and Bilateral Filter
- Sharpen images
- Flip and rotate images
- Add Gaussian noise
- Preview filter effects before applying them
- Compare original and edited images
- Save edited images to your computer

## Technologies

- Python
- Tkinter
- OpenCV
- NumPy
- Pillow

## Project Purpose

This project was developed as a learning exercise in Python GUI development and image processing.

It demonstrates how to build an interactive image editor using Tkinter and apply image processing operations with OpenCV.
